# AI Skills Assembly security policy

Report vulnerabilities through the repository's private security-advisory channel. Never put exploit details, credentials, private paths, or sensitive logs in a public issue.

Include:

- Affected file and revision.
- Reproduction steps or a minimal proof of concept.
- Expected and observed behavior.
- Impact and known mitigations.

Scope includes installer and symlink safety, hook construction, routing parsing, unsafe defaults, and repository or history disclosure. Use the normal issue tracker for non-security defects.
